# Sky-High Properties (SHP)

> Premier Real Estate Advisory & Curated Property Portfolio in Kolkata.

Sky-High Properties represents high-net-worth individuals, homeowners, and discerning buyers across Newtown, Rajarhat, EM Bypass, and Greater Kolkata. 

---

## 🌟 Key Features

- **Curated Property Catalog**:
  - **New Projects**: Institutional partnerships with Kolkata's top tier developers (**PS Group**, **Srijan Realty**, **Godrej Properties**, **Shapoorji Pallonji**, **Eden Realty**, **Vinayak Group**, **DTC Group**).
  - **Verified Resale Flats**: Secondary market residences with verified municipal mutation, clear title conveyance, and realistic ADSR valuation.
  - **Corporate & Executive Rentals**: High-floor luxury penthouses and serviced executive suites.
  - **Freehold Land & Plots**: Prime commercial corridors and residential freehold parcels.
- **Interactive Multi-Dimensional Filtering**: Real-time filtering by Developer, BHK configuration, Corridor, Budget bracket, and Keyword query.
- **Dedicated Resale Marketplace (`/resale`)**: Comprehensive secondary market portal with live search, valuation guidance, and direct WhatsApp concierge integration.
- **Owner Representation & Listing Desk**: Interactive "+ List Your Property" modal supporting Resale, Rent, and Land listings with instant forwarding to advisory specialists.
- **Strict Regulatory Integrity**: True-to-market fiduciary model focused on ADSR registry conveyance, title search, and municipal due-diligence without artificial claims.
- **Haute-Couture Editorial UI**: Bespoke luxury aesthetic built with Next.js 15, React 19, Tailwind CSS v4, Lucide Icons, and GSAP motion accents.

---

## 🛠 Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Core Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animation & Transitions**: GSAP, Lenis Smooth Scroll
- **Language**: TypeScript 5 (Strict Mode)

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or 20.x+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Himadri8991/SHP.git
cd SHP

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to experience the platform.

### Production Build
```bash
# Typecheck and build static/dynamic pages
npm run build

# Start production server
npm run start
```
